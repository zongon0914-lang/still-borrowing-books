# 專案用詞和決策

## 動手之前先讀

- 根目錄的 `GLOSSARY.md`：本專案的名詞定義和「避免混用」的說法。
- `docs/adr/`：重要決策的紀錄（目前還沒有；有的時候讀跟你要改的地方有關的那幾份）。

檔案不存在就直接繼續，不用提醒、也不用先建。

## 照名詞表用詞

寫任務標題、測試名稱、給讀者看的文字時，用 `GLOSSARY.md` 的詞，不要換成它列在「避免混用」的說法（例如「借閱冊數」不能寫成「借閱人次」）。需要的詞名詞表裡沒有，先想想是不是自己發明了專案不用的說法；真的缺，就記下來給 `/domain-modeling` 補。

## 跟決策衝突時

你的做法跟某份 ADR 衝突，要明白寫出來，不要默默改掉：

> _跟 ADR-0002 衝突，但值得重新討論，因為…_
