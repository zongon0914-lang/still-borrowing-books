# 09: 美化、手機版、最後檢查

**What to build:** 把整個網站的視覺做到可以交件：書頁質感（米白紙張色、書本感的內文字型、章節像書的章節），圖表配色統一、乾淨。所有頁面在手機上都不跑版。兩個檢查點全部跑一次、全部通過後，更新到 GitHub Pages。參賽者用作品連結在手機和電腦上各看一次，然後自己填參賽表單送出，目標 11/20 中午前。

**Blocked by:** 02, 04, 07, 08

**Status:** 本機完成（2026-11-17）；等推上 GitHub Pages、跑線上檢查、參賽者自己檢查和填表
