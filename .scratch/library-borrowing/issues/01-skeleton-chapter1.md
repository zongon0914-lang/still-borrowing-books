# 01: 骨架加章節一：台灣人一年借幾本書？

**What to build:** 讀者打開首頁，看到標題《我們這一代，還借書嗎？》、副標題和三個問題入口。點第一個問題進入章節一，看到 2014–2025 年全國紙本借閱冊數的趨勢圖（2021 年谷底特別標出），以及另一張電子書借閱圖。所有頁面共用書頁質感的版型：頁首、頁尾、麵包屑、回首頁、回上一層，以及「資料來源與 AI 使用說明」連結（先放一個暫時的頁面）。章節二、章節三的入口先放「製作中」的暫時頁面，讓連結不會壞掉。數據由資料整理模組從「公共圖書館統計」開放資料一次整理好，網站本身不即時抓 API。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 雙擊首頁就能在瀏覽器預覽，不需要安裝任何東西
- [ ] 資料整理模組產出全國 2014–2025 每年的紙本借閱冊數、紙本借閱人次、電子書借閱冊數、服務人口
- [ ] 趨勢圖滑過或點某一年，會顯示那一年的確切數字；2021 年谷底和 2025 年新高有文字標註
- [ ] 電子書借閱是獨立的一張圖，紙本和電子書沒有混在一起
- [ ] 有一個「平均每人幾本」的好懂換算
- [ ] 檢查點一基本版：自動核對 2014–2025 年中全國紙本借閱最低的是 2021 年；電子書 2024 年約 1,980 萬冊、2025 年比 2024 年少
- [ ] 檢查點二基本版：從首頁自動點每個連結，沒有壞掉的連結
- [ ] 用詞照 GLOSSARY.md（借閱冊數、借閱人次、紙本借閱／電子書借閱）
