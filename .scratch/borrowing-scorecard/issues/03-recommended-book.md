# 03: 推薦書和「換一本」

**What to build:** 借書成績單出現一本推薦書（書名、作者），從讀者這個年齡層最常借的前三類熱門書單中隨機挑一本；按「換一本」會換另一本。旁邊連結到原本的年齡工具，可以看這個年齡層完整的類別排行和書單。借 0 本的讀者也一定看得到推薦書（配合稱號那句「我們幫你挑好了」）。計算模組只提供候選清單，「隨機挑」放在畫面那一半，讓測試結果固定。

詳見 [docs/spec-scorecard.md](../../../docs/spec-scorecard.md)（使用者故事 24、25、28）。
