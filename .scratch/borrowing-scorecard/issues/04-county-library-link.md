# 04: 到自己縣市的圖書館借這本

**What to build:** 推薦書下方出現「到〇〇圖書館借這本 →」，連到讀者所選縣市的公共圖書館。能用書名直接帶入查詢的縣市，一按就打開這本書的查詢結果；不行的縣市，就打開那個縣市的館藏查詢頁。22 個縣市的圖書館名稱和網址都要實際打開核對，整理成網站數據。資料來源頁新增這份來源。換一本書時，連結跟著換。

詳見 [docs/spec-scorecard.md](../../../docs/spec-scorecard.md)（使用者故事 26、27；實作決策「新增數據」）。
