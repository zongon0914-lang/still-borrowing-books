# 05: 存成圖片與分享

**What to build:** 借書成績單下方有「存成圖片」，下載一張 1080×1920（IG 限動尺寸）的直式 PNG：讀者的借書量（估算時註明）、跟縣市和全國的比較、名次、跟同齡人的比較、稱號和一句話、推薦書、作品網址。視覺沿用網站的米白紙張色、朱紅強調色、書本感字型。瀏覽器支援分享檔案時（多半是手機），另外顯示「分享」按鈕，用系統分享選單把圖片傳到 IG、LINE；不支援時不顯示這個按鈕。圖片在讀者瀏覽器裡畫出來，不上傳到任何地方。

詳見 [docs/spec-scorecard.md](../../../docs/spec-scorecard.md)（使用者故事 29–33；實作決策「存成圖片與分享」）。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 「存成圖片」下載 1080×1920 PNG，內容齊全、文字不超出邊界（用瀏覽器實際下載檢查，附截圖）
- [ ] 長縣市名、長書名、999 本、0 本、估算這幾種情況，圖片都排得下
- [ ] 支援分享的瀏覽器顯示「分享」並能送出圖片；不支援的瀏覽器不顯示
- [ ] 換一本書後，存出的圖片用的是新的推薦書
- [ ] 兩個檢查點全部通過
