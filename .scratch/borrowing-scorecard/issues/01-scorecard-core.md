# 01: 成績單骨架：輸入 → 跟縣市、全國比 → 名次和稱號

**What to build:** 讀者從首頁（第四個入口）或章節三結論後面，進到新頁面「換你回答：你還借書嗎？」。選縣市（22 個）、年齡層（北市圖 9 組），填去年借了幾本書，或改選範圍（大概 0／1–5／6–12／13 本以上）。按下去就在同一頁看到借書成績單的第一版：跟自己縣市 2025 年人均借閱比、跟全國 2025 年人均借閱比（倍數，或還差幾本）、「如果你是一個縣市，可以排全台第幾名、贏過哪些縣市」，以及稱號和一句話（規格的使用者故事 22）。頁面寫明計算都在瀏覽器完成、不傳出也不儲存；輸入不寫進網址。錯誤輸入時顯示友善提示。這張也負責建立開發分支，之後所有任務都在這個分支上做。

詳見 [docs/spec-scorecard.md](../../../docs/spec-scorecard.md)（實作決策「成績單計算模組」、測試決策 1、2）。

**Blocked by:** None (can start immediately)

**Status:** 完成（2026-11-17，在 scorecard 分支）

備註：計算模組是 `assets/scorecard.js` 的 `Scorecard.compute(data, {county, age, books, range})`，測試在 `tests/scorecard.test.mjs`。名次的「共 23 名」是 22 個縣市加上讀者。借書量欄位用文字框（數字鍵盤），讓 2.5 這類輸入也能顯示友善提示。表單只在有 JS 時顯示、不送出，輸入不會進網址。
