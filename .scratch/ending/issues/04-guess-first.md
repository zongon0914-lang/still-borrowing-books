# 04: 先猜再看

**What to build:** 讀者一進章節一，最上面先看到「你猜，2025 年台灣人平均一年借幾本紙本書？」，拖動 0～20 本（一格 0.5 本）的拉桿、旁邊即時顯示選的數字，按「揭曉」後看到答案 5.8 本和揭曉句（猜多了幾本／猜少了幾本／差距 0.5 本以內是幾乎猜中），可以「再猜一次」。不猜的人往下捲照樣看到原本的內容和趨勢圖。揭曉句由章節一的計算那一半產生，語氣友善；猜的數字不寫進網址、不存、不送出。JavaScript 沒載入時只顯示題目和答案文字。

詳見 [docs/spec-ending.md](../../../docs/spec-ending.md)（使用者故事 26–36；實作決策「先猜再看」；測試決策「接縫二」）。

**Blocked by:** None (can start immediately)

**Status:** 完成（2026-11-17，在 ending 分支）揭曉句由 `Chapter1Page.guess` 產生，測試在 `tests/chapter1-guess.test.mjs`；瀏覽器操作還沒確認。
