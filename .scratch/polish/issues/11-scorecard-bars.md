# 11: 成績單圖片長條圖

**What to build:** 成績單產生的 1080×1920 圖片上多一組四根橫條：我、我的縣市、全國、台北同齡人，每根標出本數。選範圍的讀者「我」那一根標「約 N 本」；0 本、120 本都畫得好看，原本的稱號、比較句、推薦書、網址都還在、不重疊。

詳見 [docs/spec-polish.md](../../../docs/spec-polish.md)（使用者故事 44–49；實作決策「成績單圖片」）。

**Blocked by:** None (can start immediately)

**Status:** 完成（2026-11-17）分支 ending。`ScorecardImage.content().bars` 照抄 compute 的數字，`layout` 畫長條；最緊的排法多一層保險（說明和比較句各縮成一行）。重疊測試改成兩兩比方框。用瀏覽器實際產生 0 本、約 15 本、120 本三張圖確認。

- [x] 四個數字全部來自成績單的計算，圖片不自己算
- [x] 以最大值為滿格；「我」很大時其他三根仍看得見一小段，一律標數字
- [x] 排版放進圖片排版那一半，有測試：0 本、3 本、120 本、選範圍都不重疊、不出圖
- [x] 語氣符合 CODING_STANDARDS 第 4 條（0 本不像在罵人）
- [x] 用成績單檢查頁實際產生圖片，截圖留證
- [x] `npm.cmd test` 全過
